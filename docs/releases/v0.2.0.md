# cis v0.2.0

`cis enc` and `cis dec` now accept a folder.

## Highlights

- `cis enc <folder>` and `cis dec <folder>` replace each regular file in the
  folder and in its subfolders
- One password prompt for the full folder
- All results go to temporary files before the tool replaces a file. An error
  for one file changes no file
- A wrong password on a folder changes no file
- `cis enc` on a folder does not change a file that the same password can
  decrypt
- The tool does not change symbolic links

## Notes

- The tool does not hide file names or the folder structure.
- The temporary files of `cis enc` use approximately 1.33 times the size of
  the folder.
- The behavior with a single file or a note is the same as in v0.1.0.

## Installation

```sh
go install github.com/Thelost77/cis@v0.2.0
```

## Requirements

- Go 1.26 or newer for source installation
- Linux or macOS

`cis` has no external runtime dependencies.
