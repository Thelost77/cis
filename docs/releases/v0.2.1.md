# cis v0.2.1

`cis` now uses much less memory. The format of a secret is the same as in
v0.2.0.

## Highlights

- `cis enc` and `cis dec` keep one copy of a file in memory. A 1 GB file needs
  approximately 1.0 GB. In v0.2.0, `cis enc` needed 7.0 GB and `cis dec`
  needed 3.7 GB
- With a folder, memory use is approximately the size of the largest file
- `cis enc` and `cis dec` are not slower than in v0.2.0
- v0.2.0 can decrypt a secret from v0.2.1, and v0.2.1 can decrypt a secret
  from v0.2.0

## Notes

- With input from a pipe, the tool does not know the input size. Memory use
  can then be approximately 2.5 times the input size.
- An error for a single file now starts with the file name.
- For a single file, the tool now asks for the password before it reads the
  file.
- The tool now ignores white space in a secret.

## Installation

```sh
go install github.com/Thelost77/cis@v0.2.1
```

## Requirements

- Go 1.26 or newer for source installation
- Linux or macOS

`cis` has no external runtime dependencies.
