# cis v0.1.0

First public release of `cis`, a tiny CLI that encrypts and decrypts notes and
files.

## Highlights

- SHA-256 password hash as an AES-256 key
- Base64 secrets for notes and files
- In-place file encrypt and decrypt
- Password prompt. The password is not a command argument
- Original file mode is kept
- A wrong password does not change a file
- Linux and macOS support

## Installation

```sh
go install github.com/Thelost77/cis@v0.1.0
```

## Requirements

- Go 1.26 or newer for source installation
- Linux or macOS

`cis` has no external runtime dependencies.
